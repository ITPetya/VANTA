# Private Konfiguration (Vorlagen)

Dieser Ordner enthält nur Vorlagen. Für den Betrieb wird er nach `config/` kopiert und dort angepasst. `config/` ist in `.gitignore` eingetragen und wird nie eingecheckt.

In `config/` gehören zum Beispiel:

- Wichtig-Liste für Personen und Absender
- Nachrichtenquellen und Themen
- Schwellwerte für Gesundheitswarnungen
- Zeitfenster, Push-Budget, Ruhezeiten
- Registrierte Geräte

Die Vorlagendateien folgen mit Meilenstein M0.
