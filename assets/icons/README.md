# VANTA Icons

| Ordner | Inhalt | Verwendung |
|---|---|---|
| `ios/` | App-Icon-Set mit `Contents.json` | Inhalt in `app/.../Assets.xcassets/AppIcon.appiconset/` übernehmen |
| `web/` | Favicon, Apple-Touch-Icon, Icons für Web-Manifest | spätere Weboberfläche oder Statusseite, Einbindung siehe `web/README.txt` |
| `android/` | Launcher-Icons | derzeit ungenutzt, für eine mögliche spätere Android-App |

Das 1024-px-Icon (`ios/AppIcon~ios-marketing.png`) ist ohne Transparenz, so wie Apple es verlangt.
